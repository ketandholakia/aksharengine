# Devanagari / Hindi Font Profiles TODO

This is a tracking checklist for mapping legacy Devanagari (Hindi/Marathi) fonts into JSON font profiles for the AksharEngine. 

The list is sorted with the **most critical** legacy ecosystems at the top. Note: Unicode fonts (like Mangal, Noto Sans Devanagari, Nirmala UI) are explicitly excluded as they do not require conversion.

These ten families cover the vast majority of older Hindi/Devanagari data.
